Contributing

Development Setup

git clone https://github.com/bula173/ReqManTool
cd ReqManTool
./etc/start.sh

This creates a Python venv (backend/.venv), installs dependencies, and starts both backend and frontend dev servers.

Code Style

Backend (Python)

# Format
ruff check --fix reqman/
ruff format reqman/

# Type check
mypy --ignore-missing-imports reqman/

# Test
pytest -q

Frontend (TypeScript/React)

cd frontend
npm run lint
npm run build

Commit Messages

Follow conventional commits:

<type>(<scope>): <subject>

<body>

<footer>

Types: feat, fix, docs, style, refactor, test, chore

Example:

feat(export): add ReqIF export for operational scenarios

Adds support for exporting operational_scenarios modules to ReqIF format
including SPEC-RELATIONS for cross-module links.

Closes #123

Testing

Run the full test suite:

cd backend
pytest -q

Run with coverage:

pytest -q --cov=reqman --cov-report=term-missing

Mutation Testing

mutmut run --source-dirs=reqman/service.py --runner="python -m pytest -x -q" --max-runtime=300

Static Analysis

mypy --ignore-missing-imports reqman/
ruff check reqman/

Pull Request Process

  1. Fork the repository

  2. Create a feature branch (feature/your-feature)

  3. Make changes with tests

  4. Run full test suite (pytest -q)

  5. Run static analysis (mypy, ruff)

6. Ensure all tests pass 6. Open a Pull Request with:

  • Clear description of changes

  • Link to related issue

  • Screenshots for UI changes

Code Review Guidelines

  • All code must pass CI (tests, linting, type checking)

  • New features require tests

  • Bug fixes require regression tests

  • Documentation updated for user-facing changes

  • Breaking changes require migration guide

Release Process

  1. Update version in backend/reqman/__init__.py

  2. Update CHANGELOG.md

3. Create and push tag: git tag vX.Y.Z && git push origin vX.Y.Z 3. GitHub Actions builds wheel, creates release, publishes to PyPI 4. Frontend built and embedded in wheel
